OBS-Diff: Accurate Pruning For Diffusion Models in One-Shot

Junhan Zhu, Hesong Wang, Mingluo Su, Zefang Wang, Huan Wang*

ICLR 2026 · First author

project page / code / paper / SDXL / SD3.5-Large

Propose the first training-free, one-shot pruning framework for diffusion models, demonstrating broad applicability across diverse architectures and pruning granularities.

Cross-Resolution Diffusion Models via Network Pruning

Jiaxuan Ren†, Junhan Zhu†, Huan Wang*

CVPR 2026 Findings · Co-first author (second listed)

project page / paper

Introduce CR-Diff, a framework that repurposes network pruning to enhance generalizability by removing "adverse weights" that cause degradation at non-default resolutions.

MetaKernelBench: Measuring GPU Kernel Knowledge Transfer Beyond Code

arXiv, 2026

project page / code / paper

A benchmark of 74 paired GPU kernel problems that evaluates whether experience distilled into natural-language skills transfers between CuTe DSL and TIRx.
